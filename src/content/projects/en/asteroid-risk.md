## Near-Earth Object Surveillance

Developed in 2025, this project implements a Random Forest (RF) machine learning model to evaluate and predict the risk of collision with Near-Earth Objects (NEOs). 

The system interfaces directly with NASA APIs to pull live orbital data, distance metrics, and velocity indicators, structuring the data to train the RF model on hazardous vs. non-hazardous classification boundaries.
